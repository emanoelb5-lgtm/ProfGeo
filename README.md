# ProfGeo

Aplicativo Android de preparação para o ENA do Mestrado Profissional em Ensino de Geografia. Base: Anexo III do edital PROFGEO-UFPA n. 03/2026, ingresso em 2027.

A primeira versão inclui a unidade 1.1. O aplicativo, as unidades expansíveis e a documentação de instalação estão sendo adicionados neste repositório.
